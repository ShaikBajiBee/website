Problem Statement

The Latency Dilemma in Python HFT

  • Electronic financial markets (NASDAQ, CME) require sub-microsecond determinism.
  • Standard Python dictionary allocations trigger dynamic memory management on every order.
  • Stop-the-world Garbage Collection (GC) pauses introduce unpredictable 40+ µs tail latency spikes.
  • Memory pointer indirection ruins CPU L1/L2 cache locality.

Goal

Engineer a zero-copy contiguous binary buffer architecture in Python that eliminates heap churn while guaranteeing strict price-time priority execution.

System Architecture

High-Performance Layered Design

1. Zero-Copy Binary Core

3.2 MB contiguous memory ring buffer sliced via Python memoryview. Pre-allocated 100K 32-byte slots.

2. Matching Engine

Price-Time Priority (FIFO) matching algorithm for Limit & Market orders with partial fills.

3. Persistence Pipeline

SQLite database with atomic multi-table transactions (orders, trades, and benchmark metrics).

4. Web Trading Terminal

FastAPI asynchronous REST backend with a modern dark-themed Bloomberg-style trading terminal.

Core Innovation

Zero-Copy Binary Ring Buffer

Contiguous 32-Byte Aligned Struct Layout: <cc2sQdIQ

  • Direct Memory Packing: Orders packed directly into buffer offsets using struct.pack_into().
  • Zero Garbage Collection: No dictionary or string allocations during the hot matching path.
  • Hardware Timestamps: Nanosecond precision captured via time.perf_counter_ns().
  • Cache Efficiency: Two 32-byte order slots fit exactly within a single 64-byte L1 CPU cache line.
Matching Engine

Price-Time Priority (FIFO) Execution

  • Bids Priority: Sorted by Highest Price first; ties resolved by earliest submission sequence.
  • Asks Priority: Sorted by Lowest Price first; ties resolved by earliest submission sequence.
  • Resting Price Rule: Trades execute at the resting order's limit price.
  • Order Lifecycle: Supports partial fills, resting limit queues, and instantaneous order cancellations.
  • Market Depth: Aggregates volume across discrete price tiers for Level 2 visualization.
